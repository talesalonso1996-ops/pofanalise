# Acrescenta quintis de consumo per capita

Cria `Quintil` (base inteira) e `Quintil_RM` (só regiões
metropolitanas).

## Uso

``` r
pof_add_quintis(b)
```

## Argumentos

- b:

  Base de
  [`pof_ler_edicao()`](https://talesalonso1996-ops.github.io/pofanalise/reference/pof_ler_edicao.md).

## Valor

A base com as colunas de quintil.
