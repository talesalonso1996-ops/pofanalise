# Índice de pacotes

## Pesquisa (comece por aqui)

- [`pof_buscar()`](pof_buscar.md) : Busca produtos e categorias na
  harmonização
- [`pof_carregar()`](pof_carregar.md) : Carrega várias edições com os
  itens de interesse
- [`pof_analisar()`](pof_analisar.md) : Analisa um item ao longo das
  edições
- [`plot(`*`<pof_analise>`*`)`](plot.pof_analise.md) : Gráfico de uma
  análise
- [`pof_diferenca()`](pof_diferenca.md) : Diferença entre grupos
- [`pof_modelo()`](pof_modelo.md) : Modelo de regressão para um item
- [`pof_add_perfil()`](pof_add_perfil.md) : Variáveis de perfil da UC

## Ferramentas para ir além

- [`pof_variacao()`](pof_variacao.md) : Variação entre duas edições
- [`pof_concentracao()`](pof_concentracao.md) : Concentração e
  progressividade de um gasto
- [`pof_decompor()`](pof_decompor.md) : Decomposição demográfica de uma
  mudança
- [`pof_composicao()`](pof_composicao.md) : Composição de um grupo de
  gasto
- [`pof_elasticidade()`](pof_elasticidade.md) : Elasticidade-despesa de
  um item
- [`pof_tabela()`](pof_tabela.md) : Tabela pronta para publicação
- [`pof_exportar()`](pof_exportar.md) : Exporta um resultado para
  planilha

- [`pof_ipca()`](pof_ipca.md) [`pof_deflacionar()`](pof_ipca.md) : IPCA
